# מקדש הכוכבים

**[לאפליקציה החיה: mikdash-kochavim.vercel.app](https://mikdash-kochavim.vercel.app)**

קישור למיזוג האחרון, בלי Vercel: https://raw.githack.com/Anat1969/Horoskop-GH/main/app/index.html
(אם מופיע דף ביניים "One more step", לוחצים פעם אחת "Open the page".)

12 מבני אישיות: זיהוי, הבנה ותרגול גמישות. **מזל הוא כתובת, לא גזר דין.**

## מה יש בה
- **בית:** גלגל מזלות כאסטרולב, עם השמש של היום מחושבת בקוד.
- **אטלס:** מטריצה של 4 יסודות × 3 אופנים, עם בוררים ומצב בכתובת.
- **מבנה:** תקציר בפורמט קבוע, כוחות וצללים, גשרים עם כלל גאומטרי, שמיים ומיתוס, הייקו, פוסט, ויומן "מחשבה, מעשה, רישום".
- **אבחון:** 12 שאלות, דירוג מלא, ומדדי בהירות, עקביות וכיסוי.
- **גמישות:** 10 מצבים מהחיים, מד גמישות ונטייה למבנה שלך.
- **השמיים:** נקיפת השוויונות על ציר של 7,600 שנה, ותאריכי מזל מול תאריכי כוכבים (13 קבוצות).
- **כתבה:** מתחנה בשמיים לתחנה בנפש. בית אלפא, יפו, התלמוד וסייגן.

## הרצה
```
npm install
npm run dev
npm run build && npm run preview
npm test        # בדיקת קצה לקצה מול preview (פורט 4173)
```

## מבנה
- `src/data/content.ts`: מקור הנתונים היחיד.
- `src/data/meta.ts`: יסודות ואופנים.
- `src/lib/astro.ts`: חישובי שמש ונקיפה (Meeus, IAU).
- `src/lib/score.ts`: ניקוד האבחון ומדדי האמינות.
- `src/pages/`: הדפים. `src/components/`: רכיבים.
- `tests/`: Playwright, עם עותק מקומי של `ai-menu.js`.
